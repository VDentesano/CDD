# Project Overview: CDD (Comunicaciones y Datos) - Academic Reports

This directory is dedicated to the creation and organization of academic reports for the "Comunicaciones y Datos" (CDD) course in 2026. It contains reference materials (bibliography), formatting guidelines, and the draft/final versions of the required reports.

## Directory Overview
- **Objective:** Manage the development of technical reports on information theory, coding, data security, and communication networks.
- **Project Type:** Non-code (Academic/Documentation).

## Key Files and Directories
- `IMPORTANTE.md`: Contains the course syllabus, approval conditions, report requirements (formatting, structure), and the submission schedule. **Consult this file first for any task related to report formatting or deadlines.**
- `Bibliografia/`: 
    - `Apuntes de la Catedra-20260520/`: Specific lecture notes covering topics like Information Theory, Linear Codes, Fourier Theorems, and Queueing Theory.
    - `Libros-20260520/`: Standard textbooks (Stallings, Tanenbaum) used as secondary reference material.
- `Informe N°1. Codificacion y Codigos Lineales V2.docx`: The current working document for the first report.
- `Modelo de caratula para informe.pdf`: The mandatory cover page template that must be used for all report submissions.

## Development Conventions & Usage
- **Formatting Standards:**
    - **Font:** Arial 12.
    - **Spacing:** 1.5 line spacing.
    - **Alignment:** Justified text.
    - **Length:** Minimum of 45 pages per report.
- **Mandatory Report Structure:**
    1. Carátula (using the provided PDF template).
    2. Índice.
    3. Introducción.
    4. Cuerpo del TP.
    5. Conclusión.
    6. Bibliografía.
    7. Anexo (Optional self-evaluation).
- **Submission Workflow:**
    - Reports must be sent via email to both Theory and Practice professors.
    - All group members (2-4 people) must be CC'd.
    - Deadlines are strictly enforced as per the schedule in `IMPORTANTE.md`.
